💾 Memory Reduction
Low Memory Mode OFF
Caps max_seq_length to 1024, drops batch_size to 1 and raises grad_accum proportionally to compensate. Same effective training, ~50% less activation memory.
💡 Saves ~1–3 GB RAM. No quality loss — slower by ~2×.
Stream Dataset OFF
Instead of downloading the full HuggingFace dataset before training, only pulls the first max_samples rows directly from the stream. Avoids gigabytes of disk/RAM usage for large datasets.
💡 Saves GB of RAM on large datasets. Adds ~10–30s startup overhead.
⚡ Speed Mode OFF THROUGHPUT
Enables every speed optimization at once: adamw_8bit optimizer, tf32 matmuls (Ampere+ GPUs), sequence packing (fills full context windows instead of padding), group_by_length, multi-worker dataloading, and disables gradient checkpointing for raw throughput. Trackers (wandb/tensorboard), mid-run checkpoints, and eval loops are always disabled.
⚠️ Uses more VRAM than Low Memory Mode. Combine with Low Memory if you OOM.
🎛️ Default Training Parameters Override starting values on training pages
Per-device batch size. Lower = less VRAM/RAM.
Multiply with batch to get effective batch.
Shorter = less attention memory. 1024 recommended for low-end GPUs.
ℹ️ These values pre-fill the batch size, grad accum, and seq length fields on Fine-Tune, AutoTrain, Distillation, and AutoDistill pages when you open or save settings.
✅ Always-On Optimizations No switches needed
📋 Log Cap
In-memory log list capped at 500 entries — prevents unbounded RAM growth on long runs.
🔒 Inference Mode
All inference calls use torch.inference_mode() — lower overhead than no_grad().
🗑️ Dataset Cleanup
Dataset objects are explicitly deleted after training starts to free RAM during save phase.
🧹 GGUF Unload
GGUF teacher is fully ejected (+ VRAM cache cleared) before loading the student model in AutoDistill.
📁 No Duplicate Saves
AutoDistill no longer saves both JSONL and HF dataset to disk — JSONL only.
🚫 No Trackers
report_to="none" — wandb/tensorboard are never started, eliminating startup and per-step overhead.
💾 No Mid-Run Saves
save_strategy="no" — checkpoints are never written during training. One final save only.
🔢 Sparse Logging
Logs every 5% of steps (not every step) — eliminates Python callback overhead on short runs.
🎯 GGUF Batch Tuned
GGUF inference runs with n_batch=512 and all CPU threads — fills GPU kernels better.
⚡ Paged Optimizer
paged_adamw_8bit keeps optimizer states on VRAM, not system RAM. Already active.
